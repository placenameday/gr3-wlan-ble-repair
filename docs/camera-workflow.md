# 机友操作指南

## 先对照症状

这次实测的机身是理光 GR III，刷入前为官方 2.20。故障在更早的一次升级后出现。先是蓝牙配不上，随后发现 Wi-Fi 菜单能选「打开」，但图标仍灰，手机和 Mac 都搜不到热点。关机长按回放键也没有启动热点。即使症状相似，故障原因也可能不同。

## 在电脑上准备

从[理光官方 2.20 下载地址](https://www.ricoh-imaging.co.jp/resources/japan/support/download/digital/FIRMWARE/gr3_v220.zip)取得原厂镜像，解出 `fwdc239b.bin`。按[复现记录](reproduction.md)核对机型、版本和原厂 BIN 哈希，再让 AI 按[执行清单](ai-handoff.md)处理。用只读校验脚本检查生成的候选文件。检查失败或没有实际运行时，先停在电脑上。

## 试刷与测试

1. 备份 SD 卡内容，准备一张在相机中格式化过的空卡和一块充满电的电池。
2. 保留原厂文件备份。将已核验的候选文件命名为 `fwdc239b.bin`，单独放在 SD 卡根目录。
3. 相机关机，插卡，按住 MENU 再开机。在更新确认页核对目标版本为 **2.20**，再选择执行。如果没有正常显示确认页、版本不符或相机拒绝更新，停下并记录提示。
4. 开始写入后不要关机、拔卡或取电池。等显示更新完成，再关机、取卡并正常开机。
5. 分别确认手机能否蓝牙配对、能否连到相机 Wi-Fi 并传一张照片。记录机型、刷前版本和两项结果。

**刷写有变砖风险。** 本次只验证了一台 GR III 从官方 2.20 刷到修改版 2.20。刷回原版的路径尚未验证。 [理光官方更新步骤](https://www.ricoh-imaging.co.jp/english/support/digital/gr3_s.html)
